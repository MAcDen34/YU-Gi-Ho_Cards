## 📜 ABOUT THE PROJECT

**Pharaoh Atem's Legendary Deck** is a web-based Yu-Gi-Oh! card database that showcases the iconic cards used by **Yami Yugi (Pharaoh Atem)** from the original Yu-Gi-Oh! anime and manga. This interactive card gallery allows duelists to browse, explore, and view detailed information about the legendary cards that defined the King of Games' legacy.

### 🎯 Features

- ✅ **25+ Legendary Cards** - Dark Magician, Egyptian Gods, Exodia pieces, and more
- ✅ **Responsive Card Grid** - Beautiful CSS Grid layout that adapts to any screen size
- ✅ **Detailed Card View** - Click any card to see full stats, effects, and lore
- ✅ **Egyptian God Recognition** - Special visual effects for Divine cards
- ✅ **Animated UI** - Holo shine effects, hover animations, and duelist-themed styling
- ✅ **Mobile Friendly** - Fully responsive design for phones and tablets
- ✅ **Real-time API** - Live data from the official YGOPRODeck API

## 🚀 HOW TO USE

1. **Save all files** in the same folder:
   - `index.html`
   - `details.html`
   - `style.css`
   - `script.js`
   - `details.js`
   - `README.md`

2. **Double-click `index.html`** to open in your browser

3. **Browse the cards** - Click "VIEW DETAILS" on any card to see more information

## 📡 API REFERENCE

This project uses the **YGOPRODeck API v7**:

| Endpoint | Description |
|----------|-------------|
| `cardinfo.php?name={name}` | Fetch card by exact name |
| `cardinfo.php?id={id}` | Fetch card by ID number |

📖 **Documentation:** https://db.ygoprodeck.com/api-guide/
